# V8.3 — Correções de Login e Reuniões

## Mudanças
- Login recebeu CSS estrutural explícito para garantir split layout em desktop independentemente de utilities responsivas.
- Tela de reuniões mantém um único e-mail global de relatórios. O e-mail foi removido do formulário de nova reunião.
- Ao salvar reunião, o destinatário global é gravado no registro e o envio é tentado automaticamente se estiver configurado.
- Modal de reunião tem cabeçalho e rodapé sempre visíveis.
- Botões Fechar (X), Cancelar e Salvar ficam sempre acessíveis.
- Área de anotações aumentada para 430–470 px em tablet/desktop.
- Campos usam duas colunas a partir de 720 px; uma coluna em tablet retrato estreito/mobile.
- Nenhum workflow n8n ou contrato de API foi alterado.
